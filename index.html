🚀 Guía Integral de Flujo DevOps y Despliegue

Sigue estos 6 pasos indispensables para versionar este proyecto de Hobbies, aislar tus cambios en ramas, integrarlo con GitHub, automatizar con Open Code y publicarlo en producción con Docker en Render.

Paso 1

Uso de Git (Control de Versiones Local)

Inicia el repositorio local en la carpeta de tu proyecto y realiza tu primer commit con los archivos del Registro de Hobbies.

# 1. Abrir la terminal en la carpeta del proyecto
git init

# 2. Agregar todos los archivos al área de preparación (Staging)
git add .

# 3. Crear el primer commit
git commit -m "feat: proyecto inicial registro de hobbies y dockerfile"
Paso 2

Uso de GitHub (Repositorio Remoto)

Crea un repositorio en GitHub.com (ej. registro-hobbies-docker) y sube tu rama principal.

# 1. Renombrar la rama a 'main'
git branch -M main

# 2. Conectar tu repositorio local con el remoto de GitHub
git remote add origin https://github.com/TU_USUARIO/registro-hobbies-docker.git

# 3. Subir el código por primera vez
git push -u origin main
Paso 3

Creación de una Rama (Branching)

Crea y cámbiate a una rama aislada para desarrollar nuevas funcionalidades (ej. agregar el Agente Open Code o mejoras de UI) sin alterar main.

# 1. Crear y moverse a la nueva rama 'feature/agente-opencode'
git checkout -b feature/agente-opencode

# 2. Realizar cambios y guardarlos en la rama
git add .
git commit -m "feat: integracion de agente opencode para hobbies"

# 3. Subir la rama a GitHub
git push -u origin feature/agente-opencode
Paso 4

Unión de su Rama contra el Main (Merge)

Fusiona los cambios verificados de tu rama hacia la rama principal main.

# 1. Cambiarse de nuevo a la rama 'main'
git checkout main

# 2. Asegurarse de tener la última versión
git pull origin main

# 3. Unir (Merge) los cambios de la rama secundaria
git merge feature/agente-opencode

# 4. Enviar los cambios fusionados a GitHub
git push origin main
Paso 5

Creación de su Primer Agente en Open Code

Usa la herramienta Open Code para ejecutar o crear agentes autónomos de código y tareas inteligentes.

# 1. Instalar o verificar OpenCode
npm install -g opencode-ai

# 2. Ejecutar tu primer comando de agente autónomo
npx opencode-ai run "Crea un script que lea los hobbies y me sugiera libros relacionados"

# 3. O ejecutar el agente en Python incluido en el proyecto
python agente_opencode.py
Paso 6

Publicación en Render con Docker

Despliega este proyecto en la nube de Render utilizando el Dockerfile provisto.

# Pasos en Render Dashboard:
1. Inicia sesión en https://dashboard.render.com
2. Haz clic en "New +" y selecciona "Web Service"
3. Conecta tu repositorio de GitHub (ej. "registro-hobbies-docker")
4. En "Runtime", Render detectará automáticamente el Dockerfile (o selecciona Docker)
5. Selecciona la región más cercana y el plan "Free"
6. Haz clic en "Deploy Web Service" ¡y tu app estará online en pocos segundos!
