Guía DevOps: Git, GitHub, Ramas & Render

1. Iniciar Git Local

git init
git add .
git commit -m "feat: proyecto registro de hobbies estilo Jiron en español"

2. Subir a GitHub

git branch -M main
git remote add origin https://github.com/TU_USUARIO/registro-hobbies-docker.git
git push -u origin main

3. Crear Rama y Fusionar

git checkout -b feature/traduccion-espanol
git add . && git commit -m "feat: traduccion completa al espanol"
git checkout main
git merge feature/traduccion-espanol
git push origin main

4. Desplegar en Render con Docker

# En https://dashboard.render.com:
1. New + -> Web Service
2. Conecta tu repositorio de GitHub
3. Runtime: Docker (usa el Dockerfile incluido)
4. Plan Free -> Create Web Service
